# Frontend

Base inicial em React + TypeScript + Vite para o Portal de Chamados Engenharia.

## Estrutura

- `src/App.tsx`: composicao principal com roteamento basico.
- `src/components/layout/AppLayout.tsx`: layout base da aplicacao.
- `src/pages/HomePage.tsx`: tela inicial simples.
- `src/api/http.ts`: utilitario inicial para chamadas HTTP.
- `src/styles/global.css`: identidade visual inicial.

## Executar

```bash
cd frontend
npm install
npm run dev
```
